MT5 Trade Report Generator

INSTALLATION:
1. Make sure you have Python 3.7+ installed
2. Run: pip install -r requirements.txt
3. Run the application with: python app.py

OPTIONAL:
- Double-click setup.bat for easy installation
- Use PyInstaller to create a standalone executable:
  pyinstaller --onefile --windowed app.py

FEATURES:
- Generates Excel reports from MT5 trade history
- Supports all currency pairs
- Professional interface

NOTES:
- Requires MetaTrader 5 to be installed
- MT5 terminal must be running when using the application
